Admin Hub - Setup & Manage

📋 How It Works

  1. Load Master Roster - Upload Excel file with all member details (names, categories, paddling sides)
  2. Share Form Link - Every Monday, share the weekly form link in your group chat
  3. Members Submit - Members select their name and which days they'll attend NEXT WEEK
  4. Coach Views - Coach can see who's coming for each training day and export to Excel
